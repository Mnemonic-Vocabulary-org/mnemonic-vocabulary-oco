# Mnemonic Vocabulary

A graphical, interactive vocabulary engine for all mnemonic and visual-mnemonic techniques - how to
encode numbers, foreign words and any information - that reflects the **memory kingdom** a person
builds in their mind with those techniques, and helps to refresh those memories: re-practising each
at the best interval. It is to run on Linux - a PC and a smartphone - and maybe on Android, with the
same core everywhere.

**Status: an idea, kept so it is not forgotten.** Not being worked on in the near future; the
architecture is to come from its author. This repository holds the idea the
[ocoeco](https://github.com/open-commons-observatory/ocoeco) way - its concepts, backlog and path as
data in [`data/`](data) - so it shows in the [Open Commons Observatory](https://open-commons-observatory.github.io/).

Earlier attempts live in this organization under the name *mnevo* (2018-2022): a Vue and Node web
application and its documentation, with an architecture diagram - history to learn from.
